# ATM Interface

## Project Overview
The ATM Interface is a console-based Java application that simulates basic ATM banking operations. It allows users to securely log in and perform transactions through a simple menu-driven interface.

## Features
- User authentication using User ID and PIN.
- Maximum of three login attempts.
- Deposit money.
- Withdraw money with balance validation.
- Transfer money between accounts.
- View transaction history.
- Input validation for transaction amounts.

## Technologies Used
- Java
- Object-Oriented Programming (OOP)
- ArrayList
- Scanner
- Eclipse IDE

## Project Structure
The project consists of five Java classes:

1. **Main.java** – Starts the ATM application.
2. **ATM.java** – Handles the ATM menu and user interactions.
3. **Account.java** – Manages account details, balance, deposits, and withdrawals.
4. **Transaction.java** – Stores and displays transaction details.
5. **Bank.java** – Manages accounts, login authentication, and money transfers.

## How to Run
1. Open the project in Eclipse IDE.
2. Locate `Main.java`.
3. Right-click and select Run As → Java Application.
4. Enter a valid User ID and PIN.
5. Select an option from the ATM menu.
