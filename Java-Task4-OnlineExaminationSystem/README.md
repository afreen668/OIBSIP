Online Examination System

Project Overview

The Online Examination System is a Java-based desktop application developed using Java Swing. It allows students to log in, manage their profiles, take multiple-choice examinations, and view their results.

Objectives

Develop a simple and user-friendly examination system.

Provide secure student login.

Allow students to update their profile information.

Conduct timed multiple-choice examinations.

Calculate and display examination results automatically.

Technologies Used

Programming Language: Java

GUI Framework: Java Swing

Libraries: Java AWT and Swing

IDE: Eclipse

Features

Student Login: Students can access the system using their credentials.

Profile Management: Students can view and update their profile information.

Multiple-Choice Questions: Each question provides four options, with one correct answer.

Question Navigation: Students can move between previous and next questions.

Examination Timer: A countdown timer tracks the examination duration.

Automatic Submission: The exam is submitted automatically when the time expires.

Manual Submission: Students can submit their examination before the timer ends.

Result Display: The system displays the final score, time taken, and answer details.

Logout: Students can safely exit their session.
